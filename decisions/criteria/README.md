# Criteria versions

One file per frozen version of the criteria used to judge decks and predictions, for example `criteria_v1_2026-10-20.md`. A new criterion, such as the post hoc "quality" measure added after the Vraska game, starts a new version. It can never rescue a prediction made under an earlier version.

The criteria behind `predictions/PREDICTIONS_2026-10-20.json` are embedded in that frozen file. The first entry here should reference them, not copy them.
