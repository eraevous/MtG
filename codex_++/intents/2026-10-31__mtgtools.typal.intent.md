# 2026-10-31 mtgtools typal: census for a creature-type request

**Trigger.** Zach's blind ChatGPT test, "I would like a Merfolk deck". The agent found 35 Merfolk by searching for the word, but missed the type's support (Harmonized Crescendo, Gathering Stone, Kindred Summons, Distant Melody, Urza's Incubator). It also had no route for a typal request.

**Trade-off.** The right home for "this card works with a chosen creature type" is the KB: a typal qualifier in the contracts' query_index (C-013). It isn't there, and the Sheet Roles tags behind `capability_claims` cover only part of it. Waiting for a KB release would leave agents blind to typal support. So `typal` uses a small, declared lexical lookup over KB rules text, labels every hit `lexical_match` (exploratory), and reports `tag_gaps` so the data-layer fix has a worklist. It never decides whether a payoff applies; that stays with the DIO qualifiers. Self-dissent recorded as C-014.

**Data vs tool.** Most of the value here comes from the data. Fixing the tags and adding the qualifier (C-013) would help every verb, not only `typal`, and would let the lookup be removed.
